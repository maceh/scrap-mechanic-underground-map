POC notes — what's actually different from Depth 4

Same: slot positions/rotations (S/W/E, identical x/y/rot), elevator position (-1,-1,2), the same "everything sums to 8 chunks" design constraint, and the same shuffle(configs,2) inference (config[1] fixed to slot S).

Different: the two-piece configs use different tiles — Bot5+Top3 here, vs Bot3+Top5 on Depth 4. Notice the height order is REVERSED (bottom piece is the taller one here, 5 vs 3, opposite of Depth 4's 3-then-5) — a genuine design difference between the two drill sites, not a copy-paste artifact.

Interesting non-difference: the bevel-edge size constants in the source are written as a depth-conditional ternary (g_depth==6 and 16 or 16) that actually evaluates to the same value either way — so despite looking depth-specific in the code, the bevel geometry doesn't actually differ between Drill 1 and Drill 2. Noted as an observation, not something we "fixed."

Same descope as Depth 4: pockets, tunnel pockets, and real tunnel pathing are not modeled — still pending the unread ~1800-line section of terrain_underground.lua. No quest markers, no power toggle.
